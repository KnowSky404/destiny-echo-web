## 游戏素材分辨率

下列精灵由 `src/game/scenes/textures.ts` 的原创几何指令直接以 2 倍分辨率栅格化，并非放大旧位图；显示时补偿倍率，碰撞半径与战斗单位不变。尺寸为每张纹理的实际缓存像素，不等于屏幕占用。

| 纹理 | 逻辑画布 | 实际缓存像素 |
| --- | --- | --- |
| `player` | 64×72 | 128×144 |
| `hexer` | 56×60 | 112×120 |
| `wisp` | 48×56 | 96×112 |
| `sentinel` | 64×64 | 128×128 |
| `tank` | 64×68 | 128×136 |
| `wizard` | 60×68 | 120×136 |
| `chest` | 72×64 | 144×128 |
| `boss` | 144×144 | 288×288 |
| `friendly-shot` | 16×32 | 32×64 |
| `hostile-shot` | 20×20 | 40×40 |
| `spark` | 8×8 | 16×16 |

星阵纹理由 420×420 提升至 840×840。静态背景按 2 倍栅格化，宽度最多 4096px；防线文字按 2 倍生成。战场逻辑高度保持 800，桌面逻辑宽度 800～2400；画布背板按实际 CSS 显示面积选择 1～2 倍，不读取 DPR。1080P 的底层画布不再被迫从 800px 高放大。

「一个身位」按 68×84 逻辑单位的编队格计算：屏幕占用 = 逻辑尺寸 × 实际画布 CSS 缩放。车道间距独立换算，怪物本体直径由各自半径决定。窗口缩放实时更新显示像素，不改变当前敌人位置、人口容量或攻击格。游戏内帮助只保留核心玩法，完整规则继续在 Wiki 维护。
