# 主首领与小首领的规则边界

本轮小首领是保留兵种的独立精英角色：`role=elite`，`kind=tank/wizard`。主首领为 `role=boss`、`kind=boss`。分段导演没有把小首领改为 Boss 兵种，也没有将旧有全部 Boss 专属加成或抗控规则扩展给它；这符合本轮「独立小首领角色、保留兵种、不参与融合」的实现约定。此说明不改变冻结源码或数值。

| 规则 | 主首领 | 小首领 |
| --- | --- | --- |
| 破绽凝视 `focus` 每层20%增伤 | 生效 | 不生效；这是主首领专属加成 |
| 终焉裁决6/9层对蓄力目标的额外1.5/2倍乘区 | 生效 | 不生效；其他满足条件的终焉裁决/控制增伤照常结算 |
| 减速强度 | 原减速强度×0.5 | 不附加主首领抗性，沿用兵种的正常强度 |
| 眩晕时长 | 王权时长加成后×0.25 | 不附加主首领抗性，沿用兵种的正常时长 |
| 四次主弹或伤害门槛打断、打断后弱点 | 有 | 有，使用小首领门槛及巨像护阵/巫师仪式 |
| 敌方生命百分比的共享额度 | 2.5%最大生命/秒 | 5%最大生命/秒；两者弱点期均×2，最多积攒0.25秒 |
| 巨物的生命比例增伤、巨人/侵蚀百分比成分 | 满足自身条件即生效 | 满足自身条件即生效；这些规则没有要求 `kind=boss`，但百分比成分受对应额度限制 |
| 70/40/10%血线队列、庇护/强化召唤/重击及常规蓄力单发 | 主首领技能 | 不继承；小首领使用对应兵种的独立技能 |
| 普通嘲讽/毒素 | 不继承普通怪技能 | 不继承；只由普通怪施放，小首领使用护阵/仪式 |
| 三合一融合 | 不参与 | 不参与 |
| 完整关底奖励 | 整层完成后一次 | 不单独额外发放 |

`focus` 与终焉裁决的蓄力专属乘区分别见 [world.ts](../../../src/game/world.ts#L1972) 和 [world.ts](../../../src/game/world.ts#L1978)；减速/眩晕的主首领抗性见 [world.ts](../../../src/game/world.ts#L2136)。小首领保留 `tank/wizard` 且赋予 `elite` 角色的出生流程见 [world.ts](../../../src/game/world.ts#L1316)，角色共用的弱点和百分比额度结算见 [world.ts](../../../src/game/world.ts#L2011)。

文档中应写「主首领专属增伤/抗控」，不要将所有「首领」字样泛化为大小首领均适用。当前卡牌短文案中的「首领增伤」按上述主首领专属规则解释；说明源和设计规格需保留这一边界。今后如要让这些加成或抗性适用于小首领，应作为单独数值变更重新验证，不能在本轮冻结采样中暗改。
